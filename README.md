# CardProject

A React project built using React and Vite.

## Features

- Component-based UI using React
- Fast development with Vite
- Responsive design
- Clean and simple project structure

## Technologies Used

- React
- JavaScript
- HTML
- CSS
- Vite

## Getting Started

Clone the repository:

```bash
git clone https://github.com/Jayaditya07/CardProject.git
```

Navigate to the project folder:

```bash
cd CardProject
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open the local URL displayed in your terminal to view the project.
